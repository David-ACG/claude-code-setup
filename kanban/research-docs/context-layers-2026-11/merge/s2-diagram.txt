Diagram for "What the terms mean": how the 13 terms nest and connect
=====================================================================

Ten boxes. Labels are at most 26 characters; each note is exactly five words.
Layout: one large outer box (the context layer) with six boxes inside it, one box sitting on its
top edge (MCP), and one wide box underneath it (data access). Boxes 2 and 3 are nested.

BOXES
-----
#   Label (max 26 chars)        Note (5 words)                            Position
1   Context layer               Superset that agents draw from            Large outer box; fills most of the canvas
2   Semantic layer              Executes governed queries at runtime      Inside 1, centre, drawn with a heavier border (the only box that computes)
3   Metrics layer               Measure definitions compiled to SQL       Inside 2, as its core
4   Data catalog + dictionary   Inventory of tables and columns           Inside 1, top left
5   Business glossary           Agreed meaning of business words          Inside 1, top right
6   Ontology / knowledge graph  Entities, relationships, rules, permitted actions   Inside 1, right of 2
7   MDM and entity resolution   One ID per real thing                     Inside 1, bottom left
8   Context graph / memory      Agent working memory, kept separate       Inside 1, bottom right, inside a dashed sub-border
9   Data products / federation  Owned datasets, copied or virtualised     Wide box below 1, outside it (where the data lives)
10  MCP interface               Protocol agents use to call               Narrow box straddling the top edge of 1, with "AI agents" written above it (text, not a box)

CONTAINMENT
-----------
- Box 1 contains boxes 2, 4, 5, 6, 7 and 8.
- Box 2 contains box 3. Draw 3 filling most of 2: in practice most products sold as a semantic layer are metrics layers.
- The data dictionary is drawn as part of box 4 (it is the column-level part of the catalog), not as its own box.
- Data virtualisation is drawn as part of box 9 (one of the two ways data is reached), not as its own box.
- Box 9 is outside box 1: the context layer holds definitions and bindings, not the data itself.
- Box 8 sits inside box 1 but behind a dashed line, to show it is context the agent uses but not approved knowledge.
